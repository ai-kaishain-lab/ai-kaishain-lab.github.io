プライバシーポリシー

制定日：2026年10月31日

本ポリシーは、個人用ツール「AI実験室インサイト」（以下「本ツール」）におけるデータの取り扱いを定めるものです。

1. 利用者

本ツールの利用者は、「会社員のAI実験室」の運営者本人のみです。運営者以外の方がGoogleアカウントで本ツールに許可を与えることは想定していません。

2. 取得するデータ

  • 運営者本人のYouTubeチャンネルの集計値（再生回数、視聴時間、視聴維持率、流入元、登録者数の増減など）と、動画の基本情報（タイトル、公開日時、動画の長さなど）
  • 運営者本人のInstagramアカウントのリールの集計値（閲覧数、リーチ、平均再生時間など）

Googleユーザーデータへのアクセスは、読み取り専用の権限（youtube.readonly、yt-analytics.readonly）に限定します。視聴者個人を特定できる情報は取得しません。

3. 利用目的

取得したデータは、運営者本人が自分の投稿内容を振り返り、改善するためだけに利用します。

4. 保存場所

  • 認証情報（アクセストークン等）は、運営者本人のPC内にのみ保存します。
  • 集計値は、運営者本人のPCと、運営者本人のGoogleドライブ上のスプレッドシートに保存します。

5. 第三者への提供

取得したデータを第三者に販売・提供・共有することはありません。広告目的にも利用しません。運営者が自分の分析を補助するためにAIアシスタントへ集計値を渡すことがありますが、その場合も利用目的は3.の範囲に限ります。

6. Google API サービスのユーザーデータに関するポリシーの遵守

本ツールによるGoogle APIから受け取った情報の利用と他のアプリへの転送は、限定的使用の要件を含め、Google API Services User Data Policy に従います。

7. 許可の取り消しとデータの削除

Googleアカウントの「サードパーティ製のアプリとサービス」から、いつでも本ツールへの許可を取り消せます。取り消し後、本ツールはデータを取得できなくなります。保存済みの集計値は、運営者が自身のPCとスプレッドシートから削除できます。

8. 改定

本ポリシーを改定する場合は、このページを更新します。
